# 📊 GitHub visualization site  

## 📖 Description  

An interactive site where you can **visualize your GitHub presence**.  
Built for the **[Hack Club – Summer of Making](https://summer.hackclub.com/)** event.  

Log in with **GitHub OAuth** and generate a graph where nodes represent:  
- 📦 Repositories you’ve contributed to  
- 🏢 Organizations you’re part of  
- 👤 Or explore the network of any other GitHub user  

---

## ✨ Features  

- 🔐 Login with **GitHub OAuth**  
- 🧑‍💻 Visualize your repositories and organizations  
- 🔍 Explore graphs of other GitHub users  
- 🌐 Interactive graphs
- 📈 A fun way to explore open-source networks  

---

## 🛠️ Getting Started

1. Clone repository
2. Install dependencies: `pnpm install`
3. Fill in .env based on .env.example
4. Run it `pnpm dev`
